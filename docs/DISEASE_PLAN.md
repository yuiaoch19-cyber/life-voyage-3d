# 方案：病变器官与正常器官对比（v5「健康对比」迭代）

> 立项：2026-11-01。定位：**预防教育**，不是猎奇病理展。
> 一句话：让用户亲手把健康的器官"拖"成不爱护它的样子，再告诉他们怎么拉回来。

## 0. 医学内容红线（先读）

1. **不构成诊断**：所有病变展示都是教育性模拟（标注"非真实病理标本"），不做任何"你是否有病"的暗示；
2. **正向叙事**：每个病变必须配"可逆性/预防"信息（这是本功能的存在意义）——展示代价，更展示回头路；
3. **可查证**：每条事实带 reference（默沙东大众版 / WHO）；拿不准的数字不写；
4. **视觉克制**：只做颜色/体积/表面质感的变化，不做溃烂、脓液、出血等惊悚表现（延续全站"无血腥"红线）；
5. **选择标准**：只收录与生活方式强相关、预防手段明确的病变（可干预 = 有教育价值），首期 4 个。

## 1. 首期病变清单（全部可逆/可延缓，正向叙事）

| 器官 | 病变 | 视觉变化 | 核心事实（带来源） | 可逆性 |
|---|---|---|---|---|
| 肺 | 吸烟者的肺 | 灰黑斑驳（碳末沉积）、表面粗糙 | 肺泡壁破坏→交换面积缩小；纤毛受损 | 戒烟数周纤毛再生，数月肺功能改善；10 年肺癌风险减半（WHO） |
| 肝 | 脂肪肝 | 黄腻变色、肿大 9%、油亮 | 肝细胞内脂肪堆积，边缘变钝 | 单纯性阶段**完全可逆**：减重 5%+运动即可显著消退（默沙东） |

## 2. 技术方案（不引入任何新资产，全程序化）

### 2.1 病变着色器（核心）
对器官的 `MeshPhysicalMaterial` 做 `onBeforeCompile` 注入：
- **顶点**：沿法线的两阶 value-noise 位移（表面凹凸/粗糙化），量 = `uDisplace × uDisease`；
- **片元**：albedo 向病变色 `uDiseaseColor` 混合（×uSqDisease），高频率噪声阈值出**斑点**（碳末/瘢痕/油斑）；
- 体积变化（肿大/缩小）不走 shader，用 `mesh.scale` 插值（干净且可逆）；
- 每个 `uDisease` 0→1 连续可调 = 用户拖滑杆"看着器官生病"，这是本功能的灵魂交互。

### 2.2 并排 A/B 对比
- 「并排对比」按钮：克隆当前器官 mesh，共用几何体，克隆材质固定 `uDisease=1`；
- 左右分开（沿相机右向量各让 0.45×器官宽度），相机自动框住两者；
- 退出（换器官/Esc/再点按钮）→ 移除克隆、复位位移与缩放、飞回原机位。

### 2.3 数据 schema（organs.json 扩展）
```jsonc
"disease": {
  "name": "脂肪肝",
  "color": "#d9b45a", "spotColor": "#c9a13e",
  "displace": 0.004, "noiseScale": 6, "spotDensity": 0.35, "scale": 1.09,
  "changes": ["…", "…"],
  "reversible": "…",
  "reference": "…"
}
```

### 2.4 UI（信息面板内，位于「如何善待它」之前）
- 区块标题「健康对比 · 病变模拟」+ 小字"教育性模拟，非真实病理标本"；
- 滑杆「如果不好好爱护它…」0–100%，实时驱动该器官的 uDisease/scale；
- 变化清单（changes）在滑杆 >0 时展开；
- 「✦ 回头路」行：reversible 文案（暖色高亮——本功能的情绪锚点）；
- 「并排对比」按钮。

### 2.5 交互规则
- 换器官/关闭面板/Esc → 病变滑杆归零、克隆移除（不留残余状态）；
- 器官被 solo 隔离时对比功能照常可用；
- 器官无 disease 配置 → 面板不渲染该区块（皮肤/气管等首期不做）。

## 3. 验收标准

- [ ] 四个器官的滑杆拖动全程平滑（变色+斑点+凹凸+体积同步渐变，无跳变）
- [ ] 并排对比：健康/病变同框、机位正确框住两者、退出后无残影
- [ ] 每个病变的 changes/reversible/reference 齐全且语气正向
- [ ] 面板区块含"教育性模拟"小字；换器官状态清理干净
- [ ] tsc + 生产构建通过；巡游模式与病变功能不互相干扰
