# 方案：v9「让身体活起来」— 生理动效 + 声音 + 食物之旅

> 状态：**P0 + P1 全部完成（2026-11-02）**——心脏搏动 / 呼吸+膈肌 / 心音合成 /
> 食物之旅 / 章节模式。P2 收尾杂项（截图按钮文案、字幕字号自适应）待做。

## 0. 交互红线（延续）

- 所有动效默认优雅克制：搏动幅度 ≤5%、呼吸 ≤3%，宁可看不见也不要卡通抽搐；
- 心音默认**关闭**（部分用户场合不适合），HUD 增加声音开关；
- 动效频率全部有医学依据（心率跟滑杆、呼吸固定 14 次/分）。

## P0-A 心脏搏动（与心率滑杆实时联动）

现状：心脏静止，只有 HUD 图标在跳。

规格：
- 心脏 mesh 缩放叠加心跳包络：`scale = 病变缩放 × (1 + 0.045 × heartbeat(t, bpm))`；
- 包络复用现有 `heartbeat()`（主搏+次搏的 lub-dub 双峰）——滑杆拖到 120 时心脏真的狂跳；
- 与病变模拟共存：搏动乘在病变缩放之上（枢轴已重定向，原地搏动不位移）；
- 主动脉根部粒子亮度同步增强（已有 uPulse 通道，接上即可）。

验收：心率 50 与 120 两档下，搏动频率/幅度肉眼可辨且不卡通；病变 85% 时搏动正常。

## P0-B 呼吸节律（肺 + 膈肌）

规格：
- 新增「膈肌」网格：BP3D `FJ3131 Diaphragm`（8469 顶点，走现有 readBP3DPart 管线），
  淡红肌肉材质，归入呼吸系统，可点选（面板：呼吸的引擎）；
- 肺 mesh 缓慢缩放 `1 ± 2.5%`（正弦，14 次/分 ≈ 0.23Hz），吸气相膈肌下沉
  （y 位移 −0.008）、肺扩大——联动但反相；
- 呼吸频率固定 14 次/分（不与心率滑杆联动，避免误导）；
- 支气管树粒子密度随吸气相轻微增强（+20%，可选微效果）。

验收：全景视角下可见胸腔起伏；膈肌与肺反相；呼吸与心跳各自独立节律。

## P0-C 心音（WebAudio 合成，零素材）

规格：
- HUD 新增「声音」开关（默认关）；开启时用 WebAudio 合成 lub-dub：
  两次低频衰减振荡（55Hz/70Hz，指数衰减 80ms），严格对齐 `heartbeat()` 包络的主/次峰；
- 音量随 BPM 包络增强（120bpm 时明显更急促）——听觉与视觉完全同步；
- 移动端 iOS 需首次触摸解锁 AudioContext（在首次 pointerdown 恢复）。

验收：开启后心率 72 听感为规律的 lub-dub；拖到 120 可感知加速；关闭后完全无声。

## P1-D 食物之旅（消化路径粒子 + 讲解）

规格：
- 路径：食管 → 胃 → 十二指肠 → 小肠（上/下）→ 回盲部 → 升/横/降结肠 → 直肠，
  用各器官包围盒中心 + 关键解剖弯点手工串成 CatmullRom（锚点均在 anchors.json）；
- 一颗琥珀色「食物球」+ 尾迹粒子沿路径循环，途经器官时轻微增亮；
- 巡游字幕联动：行至某段时字幕显示该段讲解（"正在经过：十二指肠"）；
- 触发：消化系统过滤器下自动播放 + HUD 可关。

验收：路径全程 40–60 秒走完，途经处无穿插穿模；与血流粒子颜色明显区分。

## P1-E 章节模式（三大主题之旅）

规格：
- 巡游从"随机器官轮播"升级为三个可选章节：血液循环之旅 / 呼吸之旅 / 神经信号之旅；
- 每章节 = 固定站点序列 + 专属字幕文案（3–5 句/章，文案终审流程同 v8.1）；
- 例：神经信号之旅 = 脑 → 脊髓 → 臂丛 → 正中神经 → 坐骨神经，途经时信号粒子爆发。

验收：三章节各走一遍无卡顿、字幕与站点对齐、可随时切回普通巡游。
