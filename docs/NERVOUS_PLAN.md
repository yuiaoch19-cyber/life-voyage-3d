# 方案：v7「神经系统完善」— 神经传输线 + 重要节点交互

> 立项：2026-11-01。定位：把神经系统从"只有一个脑"升级为
> **脑 → 脊髓 → 外周神经的完整网络**，用"神经信号流"让网络活起来，
> 在关键节点提供可点击的讲解。延续 v4 粒子流的成功模式。

## 0. 医学事实底座（已核对，写入节点卡片时带 reference）

- 坐骨神经：全身**最粗最长**的神经，直径约 2cm（比脊髓还粗），起于 L4–S3，
  出梨状肌下孔，行至腘窝分为胫神经与腓总神经（Cleveland Clinic / TeachMeAnatomy）；
- 脊髓：成人长约 **43–46cm**，止于 **L1–L2** 水平（圆锥），以下为马尾——
  因此腰穿在 L3/L4 以下是安全的；
- 迷走神经（CN X）：**最长脑神经**，"vagus=游走"，从脑干走到胸腹腔；
  **80–90% 为传入纤维**（器官→脑），主导"休息与消化"副交感。

## 2. 功能规格

### F1 神经网格（nervous.glb）
脊髓 + 外周神经干 + 臂丛 + 马尾 合并为 `o.nerves`（有机材质补丁、淡黄色 #f3e27a）。
可见性：`系统=全部(低不透明) | 系统=神经(高不透明) | solo 上下文`。

### F2 神经传输线（粒子流第二实例）
- 路径：从每根神经部件提取中心线（v4 同款 PCA 分箱法），方向 = 从脑/脊髓向外周；
- 视觉：亮黄 #ffe066 小粒子 + **脉冲波包**（alpha 乘以行相位 traveling wave，
  信号成"一簇一簇"地传导，区别于血流的连续流）；
- 规模：≤ 2 万粒子（粒子总量预算：血 7.7 万 + 神经 2 万 = 9.7 万，GPU 无压力）。

### F3 重要节点交互（5 个）
| 节点 | 锚点 | 卡片要点 |
|---|---|---|
| 脊髓 | spinal_cord 中心 | 43–46cm / L1–L2 / 马尾与腰穿安全区 |
| 臂丛 | brachial_plexus 中心 | C5–T1 编织网，上肢"总线" |
| 正中神经 | median_nerve_l 中心 | 腕管综合征与"手机手"预防 |
| 坐骨神经 | sciatic_nerve_l 中心 | 全身最粗最长 ~2cm，久坐压迫 |
| 迷走神经 | vagus_nerve_l 中心 | CN X 游走者，肠脑轴热线 |

交互：节点 = 发光小球标记（脉冲缩放）→ 点击 → 相机飞近 + 信息面板（同器官面板，
含 summary/structure/facts/careTips 全字段）+ 该节点所在神经的粒子**信号爆发**（全局 burst uniform 1.5s）。

### F4 模式与互斥
- 神经系统过滤器：粒子/网格全亮 + 节点脉冲；
- 测验题库纳入神经节点（找一找"坐骨神经"）；
- 巡游路线纳入脑与坐骨神经两站；
- 与血管/粒子/病变互斥规则沿用现有 store 门控。
