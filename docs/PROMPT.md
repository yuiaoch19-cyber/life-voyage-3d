> **⚠️ v4 全人体粒子流决议（2026-10-31，用户反馈：粒子只覆盖一小部分，体现不了全人体）**
>
> 1. **粒子路径 = 手写主干 + 自动中心线**：手写曲线只负责 9 条解剖锚定的主干
>    （主动脉/颈动脉/冠状动脉/肾动脉/腔静脉/肺动脉）；其余血管由
>    `build-organs.mjs` 从 BP3D **每根真实血管部件**自动提取中心线——
>    PCA 求主轴 → 沿轴 12 分箱取均值 → 离心/回心方向判定（对比两端到心脏的距离）→
>    长度 <3.5cm 的碎片丢弃。产出 `src/data/vessels-auto.json`（159 条）。
> 2. **规模下限**：总流道 ≥ 168 条、总粒子 ≥ 7.5 万（桌面）；移动端减半。
> 3. **踩坑**：中心线分箱索引用 Float32 存投影值，而 min/max 用 float64 比较，
>    舍入差会 floor 出 -1 —— 分箱索引必须 clamp。含 NaN 的部件要整根剔除。
> 4. **器官几何精化**：三角 <1.2 万的器官做中点细分(4×) + 2 轮拉普拉斯平滑(λ=0.35)
>    + 面积加权法线重算（`refineGeometry`）；心/肺/脑/皮肤/气管跳过（保细节或已够密）。
>    细分按"数边→一次分配"写法，避免逐边扩数组的 O(n²)。

> **⚠️ v3.1 体验完善决议（2026-10-31，用户反馈：粒子密度太小、选器官要能隐藏血管、要更完整）**
>
> 1. **粒子规模下限**：总粒子 ≥ 5 万（各主干 3200–12800），`uPointSize = dpr × 1.7`，
>    距离衰减系数 7.0、尺寸上限 18px、基础 alpha 0.9。**粒子"看不到"永远是缺陷**，
>    调参时以血管视图全景观感为准。
> 2. **血管管壁与粒子流是两个独立开关**（「血管」/「粒子流」）：
>    选中器官时可只关「血管」留下粒子讲故事，也可全关得到纯器官特写。
>    血管视图（只看血管）强制显示管壁。
> 3. **巡游模式**：6.5s/器官自动轮播（相机飞行+信息面板联动）；
>    任何手动交互（点选/导航/关闭面板/回全景）立即停止。
> 4. **一键截图**：`postfx.render(0)` 后同步 `canvas.toBlob`（无需 preserveDrawingBuffer），
>    文件名带当前器官 id。
> 5. 器官建模已用最优开源层（Z-Anatomy standard 档 + BP3D + HuBMAP）；再往上是
>    NIH 3D CC0 单器官精修，属可选增强，不作为默认承诺。

> **⚠️ v3 交互完备性决议（2026-10-31，用户实测反馈：模糊、粒子不可见、缺血管视图、缺选中隔离）**
>
> 1. **模糊根因（最高优先级教训）**：`WebGLRenderer` 创建后**必须立即**
>    `renderer.setSize(window.innerWidth, window.innerHeight)`。漏掉这一行时画布缓冲
>    停在 three 默认的 300×150，被 CSS 拉伸全屏 = 强模糊 + 粒子糊成不可见；
>    而且开发者自己的截图会因意外触发过 resize 事件而"看起来正常"——
>    **任何渲染异常先用 `renderer.getContext().getParameter(gl.DRAWING_BUFFER_SIZE)` 验证缓冲尺寸**。
> 2. **选中即隔离**：`solo` 默认开启。单击器官 → 隐藏体格层与其它器官 + 相机飞近；
>    「只看选中」开关可关闭此行为恢复"变暗"模式。
> 3. **只看血管**（新视图模式）：开启后隐藏体格层与全部器官，仅保留血管树 + 粒子流，
>    相机回全景；点击任何器官自动退出该模式。
> 4. **双击空白处 = 回全景机位**；`Esc` 按层级关闭（关于页 → 面板/选中）。
> 5. **粒子可见性规则**（汇总）：`depthTest: true` + NormalBlending 实心红点 +
>    每粒子流速差 0.72–1.28×；可见性 = `flow 开` 且 `系统 ∈ {全部, 循环} 或 solo/血管视图`。
> 6. 心脏特写机位拉近至 dist≈0.5（心脏为唯一主角时的戏剧感机位）。

> **⚠️ v2 视觉改版决议（2026-10-31，依据用户实测反馈，优先级高于下文旧描述）**
>
> 用户反馈：发光刺眼、缩小时模糊、细节被泛光吞没、血管不完整、粒子无颗粒感、
> 缺少"看局部时隐藏其它"的功能。据此**放弃"加色发光全息"路线**，切换为
> **影棚哑光 PBR**（对标 Zygote Body 的实心材质与隔离显示、BioDigital 的影棚打光、
> human-atlas 的真实血管网格）：
>
> 1. **无 bloom、无 FXAA、无自发光**——composer 只有 Render → Outline → Output；
>    唯一的"发光"是悬停描边。X 光 shader 保留但大幅调暗（base 0.0004 / strength 0.16 / pow 4.5），
>    仅作为体格层的可选模式，默认模式为**实体（分层透明）**。
> 2. **分层透明**：默认不透明度 0.6；皮肤 = 滑块 × 0.55（外层更透），肌肉/骨骼 = 滑块原值；
>    depthWrite 仅在 opacity > 0.8 时开启，保证"缩小时不糊、能看进体内"。
> 3. **完整血管树**：不再只靠手写曲线。从 BodyParts3D 提取 **96 条动脉 + 80 条静脉真实网格**
>    （32 万三角，`vasculature.glb`），动脉深红 `#a03030` / 静脉灰蓝 `#46628f`，
>    半透明管壁（0.85/0.75, depthWrite off）。手写曲线只负责 9 条主干上的**粒子流动**。
> 4. **粒子要有颗粒感**：小而实的圆粒（硬边 smoothstep 0.5→0.3，尺寸上限 15px），
>    每粒子自带流速差（jitter 0.72–1.28×），`depthTest: true` 嵌入血管树内部被正确遮挡；
>    **禁用 additive**——红光叠在亮青色上会被稀释成白色（实测教训）。
> 5. **「只看选中」（solo）**：选中器官 + solo 开启 → 隐藏体格层与其它器官，
>    只留选中器官 + 血管树 + 粒子流（解剖上下文）。
> 6. 每器官**专属颜色**（organs.json `color` 字段），不再同系统同色。

## 0. 立意与边界（先读，不可违背）

**愿景**：让每个普通人"看见生命的奇迹"。我们用自己的心跳、呼吸和思考生活着，
却很少有机会直观地看见它们如何发生。本项目用 WebGL 把人体变成一座
可旋转、可点击、会"流动"的光之雕塑——它不是猎奇或恐怖秀，而是一封写给身体的情书：
看懂它，才会珍惜它、善待它。

- **定位**：交互式 3D 人体科普 / 教育演示（Web 端，单页应用）。
- **基调**：温暖、明亮、有敬畏感。血液不画成写实红色液体，一律用"发光粒子流"表达；
  无血腥、无惊悚、无疼痛意象。
- **红线**：
  1. 不提供任何诊断、用药或治疗建议；信息面板全部为科普内容；
  2. 所有数字型医学事实必须带 `reference` 字段标注权威来源；
  3. 页脚固定展示免责声明：「本作品仅供健康教育科普，不构成医疗建议」；
  4. 使用的第三方模型/代码必须遵守 `RESEARCH.md` 列出的许可证并在"关于"页署名。

## 2. UI 设计（对标热门视觉）

**风格名**：「深空实验室」— 暗色玻璃拟态 + 极光渐变，参考 Apple visionOS 玻璃层、
Linear 暗色主题、Apple Health 数据卡。

- **色板**：
  - 背景深空 `#0B1220` → 底部极光渐变（青紫，透明度 ≤ 8%）；
  - 玻璃面板 `rgba(255,255,255,0.06)` + `backdrop-filter: blur(16px)` + 1px `rgba(255,255,255,0.12)` 描边、24px 圆角；
  - 主强调色 青 `#22D3EE`；动脉粒子 `#F87171`（暖光红）、静脉粒子 `#38BDF8`（天蓝）；
  - 文本 主 `#E2E8F0` / 次 `#94A3B8`；健康提示统一用暖橙 `#FBBF24` 图标 + 文案。
- **字体**：`system-ui` 栈（优先 MiSans / HarmonyOS Sans / PingFang SC / Inter）；
  数字用 `font-variant-numeric: tabular-nums`。
- **布局**（自上而下）：
  1. **顶栏**（玻璃条）：左 Logo「生命奇旅」；中 系统切换 Segmented Control（全部/循环/呼吸/消化/神经/泌尿/骨骼）；右 搜索框 + 「关于」。
  2. **左栏**：器官导航列表，按系统分组，悬停联动 3D 高亮，点击=选中。
  3. **右侧滑出信息面板**（40vw，max 480px）：见 R4。
  4. **底部状态条**：透明度滑块、「心率」滑块（60–120 BPM，驱动粒子速度与节律）、
     剖切开关、粒子流开关、重置视角。
  5. **加载页**：品牌字样 + 进度条 + 一句正面文案（随机轮换，如
     「你的心脏今天会跳动约 10 万次——先替它说声谢谢」）。
- **微交互**：面板滑入 spring 缓动；悬停器官 tooltip 跟随鼠标；双击空白处回全景；
  `Esc` 关闭面板；选中器官相机飞近后其余器官降为 15% 透明度。

## 3. 功能需求（R1–R10）

- **R1 场景装配**：人体由三层组成——皮肤层（整体，X-ray fresnel 半透明材质，可一键淡出）、
  骨骼层、器官层。加载后相机从远处推入全景机位。
- **R2 器官集**：首版 ≥10 个**独立命名 mesh**：心、肺×2、肝、胃、小肠、大肠、肾×2、脑、膀胱
  （随模型资产可扩展脾、胰、食管、气管、甲状腺）。每个 mesh 的 `userData` 携带器官 id。
- **R3 拾取与高亮**：Raycaster 悬停 → OutlinePass 描边 + tooltip（中英文名）；
  单击 → 选中（相机飞近至该器官预设机位、面板滑入）；再次单击空白 → 取消。
- **R4 信息面板**（内容全部来自 organs.json）：
  名称（中/英）、所属系统、一句话功能、结构要点 2–3 条、趣味数据 3–5 条（每条带来源）、
  「如何善待它」健康贴士 1–2 条（只讲生活方式：睡眠、饮水、运动、饮食，不做医疗建议）。
- **R5 系统过滤**：顶栏切换系统 → 不相关器官淡出至不可拾取；「全部」恢复。
- **R6 血管粒子流**（标志性效果）：
  - 曲线：≥6 条主干 CatmullRomCurve3（升主动脉→主动脉弓、肺动脉干、肺静脉、上腔静脉、
    下腔静脉、冠状动脉简化环），存 `vessels.json`（控制点数组）；
  - 渲染：`THREE.Points` + 自定义 shader。每粒子一条归一化进度 `t`，
    顶点着色器内 `t' = fract(uTime * speed + t)` 沿曲线采样位置（曲线采样点烘焙进 DataTexture），
    全程 GPU 侧流动，粒子规模 3–5 万（移动端减半）；
  - 视觉：additive blending、尺寸随 t 有呼吸感、动脉暖红/静脉天蓝双色；
  - 节律：`uHeartRate` 滑块联动速度，并叠加心跳脉冲 easing（快-慢-歇），
    让粒子"随心跳奔涌"而非匀速——这是正能量的情绪锚点；
  - 可整体开关，关闭时显示半透明静态血管管线。
- **R7 剖切与透明**：器官整体透明度滑块（0–100%，用于"看进体内"）；
  轴向剖切平面（矢状/冠状，可拖动位置，可关闭）。
- **R8 性能**：桌面 1080p 稳定 60fps；DPR 上限 2；资产懒加载 + Draco；所有 GLB 总量 < 30MB；
  移动端（宽 <768px）：粒子减半、bloom 关闭、面板改为底部抽屉。
- **R9 文案**：全站中文优先，术语附英文；语气温暖、不吓人；错误兜底页同风格。
- **R10 合规**：「关于」页列出：免责声明、医学内容参考来源、模型与代码署名
  （按 `RESEARCH.md` §4 的署名文案逐条照抄，不得删改）。

## 4. 数据来源与医学准确性

- 内容骨架先用常识性科普事实搭建，示例（已核对，可直接用）：
  - 心脏约拳头大小，每天跳动约 10 万次、泵出约 7000 升血液；
  - 肺内约有 3 亿个肺泡，摊开面积约 70 ㎡；
  - 脑约有 860 亿个神经元；
  - 全身血管连起来约 10 万公里，可绕地球两圈半；
  - 两个肾每天滤过约 180 升原尿，最终浓缩成 1–2 升尿液。
- 上线前核对要求：所有数字逐条对照权威来源（默沙东诊疗手册大众版、WHO 科普页、
  教科书），来源名写入该条数据的 `reference`；核对不了的数字直接删除，宁缺毋滥。
- 趣味数据优先选"积极、可感知"的（如"绕地球两圈半"），不用死亡率、患病率等负面数据。

## 5. 数据 Schema

```jsonc
// src/data/organs.json
{
  "id": "heart",
  "nameZh": "心脏", "nameEn": "Heart",
  "system": "circulatory",
  "summary": "一台永不休息的肌肉泵，把血液送往全身每一个角落。",
  "structure": ["四腔结构：两房两室", "左心室壁最厚，负责把血泵向全身"],
  "facts": [
    { "text": "每天跳动约 10 万次，泵出约 7000 升血液", "reference": "默沙东诊疗手册大众版·心脏概述" }
  ],
  "careTips": ["规律有氧运动是最实惠的强心剂", "充足睡眠帮助心脏减压"],
  "camera": { "position": [1.2, 0.3, 2.4], "target": [0, 0.1, 0] }
}
```

```jsonc
// src/data/vessels.json — 每条 = 一组控制点 + 类型
{ "id": "aorta-arch", "type": "artery", "points": [[0,1.2,0], [0.1,1.45,-0.05], ...] }
```

## 已知坑与实测事实（每条都踩过，勿重蹈）

- **心脏搏动方向**：心室收缩(systole)=缩小，不是膨胀。pulse 峰值时 scale 应**减去**
  而非加上位移量——`scale × (1 - amp × pulse)`，否则看起来像心脏在充气而非泵血。
- **跨衍生物体对齐必须实测**：Z-Anatomy 的两个衍生版本（hpfrei 体格 / authorOd 神经）
  在 Z 向（体厚）上差 4cm+，按高度统一缩放救不了——用分带测量工具
  （tools/measure-nerve-fit.mjs）量化后做逐轴压缩（神经 z×0.78 锚定脊柱平面）。
  **节点锚点也必须做同样的压缩**，否则节点球偏离管道。

- **材质级 visible 会压过网格级 visible**——按网格显隐时必须确认其材质没有被其它规则
  整体隐藏（v7.3：solo 神经节点时神经网本体被 organ 循环整体隐藏，节点成了孤球）。

- **跨衍生物体对齐必须实测**：Z-Anatomy 的两个衍生版本（hpfrei 体格 / authorOd 神经）
  在 Z 向（体厚）上差 4cm+，按高度统一缩放救不了——用分带测量工具
  （tools/measure-nerve-fit.mjs）量化后做逐轴压缩（神经 z×0.78 锚定脊柱平面）。
- **bash 内联 node -e 写含模板字符串/`${}` 的补丁必被 shell 插值破坏**——补丁一律用
  Edit 工具或独立 .mjs 文件；补丁失败可能吞掉大段代码，先 `node --check` + grep 结构再跑。

- **系统过滤器与 solo 的可见性规则必须按「选中器官的系统归属」判定**，而不是把
  `s.solo` 直接塞进 OK 表达式——后者会让任意系统下 solo 任一器官时，整套血管树/
  神经网/节点全部涌入画面（用户报告的"点击出现全部实体"）。
- **标注锚点的左右定侧要按解剖学**（器官自身 x 坐标符号：病人右=观众左），无脑交替
  左右会把肝标到观众右侧、胃标到观众左侧。
- **多片拼装的器官网格必有接缝重复顶点**（同位置两份顶点、法线各异）——任何沿法线的
  shader 位移都会把它们拉开成黑缝。精化管线必须以 **weld（按位置焊接）开头**：
  焊接 → 细分 → 平滑 → 重算法线；位移才可能无缝，且跨接缝平滑正是「肉感」来源。

- **gltf-transform 的 `node.setTranslation` 接收一个 vec3 数组**，不是三个参数——传三参数
  会把第一个数字当成整个 translation（JSON 里变标量），GLTFLoader `fromArray(标量)` 读出
  undefined，器官 transform 全废且无任何报错。
- **器官枢轴必须在构建期重定向到自身包围盒中心**（几何减去中心 + 节点 translation=中心）。
  否则任何 `mesh.scale` 类效果都会绕脚底原点缩放，器官"越变越往上跑"。

- **GLTFLoader 会剥掉节点名里的 `.`**（`o.heart` → `oheart`），原始名保存在 `userData.name`；
  一切按名称匹配的映射必须读 `userData.name` 兜底。
- **additive 叠加的亮度 = 层数 × 单层 alpha**：826 层肌肉骨骼网格叠加时，哪怕单层
  base 只有 0.001，轮廓处数十层掠射面叠起来依然爆白。调参公式：先算"一条视线上
  大概穿过多表面"，把 base 压到 `0.1/层数` 以下。
- **additive 红粒子叠在亮青色体格层上会变白消失**——粒子必须用 NormalBlending 实心点。
- **rAF 会在浏览器面板隐藏/失焦时挂起**：开发调试用 `window.__lv.frame(n)` 手动驱动
  （仅 dev 模式注入）；应用本身对真实用户无此问题。
- **`[hidden]` 属性会被 `display: grid` 等 CSS 覆盖**——全局补 `[hidden]{display:none!important}`。
- `store` 初始状态不会自动应用到场景——启动时必须用哨兵 prev 显式调一次 applyState。
- OutlinePass 在 bloom 之前（有 bloom 时 bloom 放最后），否则描边被泛光吃掉。
- Draco/meshopt 双压缩的 GLB：DRACOLoader 指向 `public/draco/`（本地文件，不依赖 CDN）。
- BodyParts3D 二进制布局：`positions(f32) → normals(i16 归一化) → pad4 → indices(u32)`，
  全部按部件在 atlas.json 里给字节偏移。
- authorOd 分块容器：单网格 + 每顶点 `_ID`(u16) 属性存**全局网格号**（不是本地序号），
  position/normal 为 i16 归一化 + 节点矩阵反量化。
- 微信/移动端若加载慢：vasculature.glb 8.4MB 未压缩，后续可用 meshopt 压到 ~3MB。
