# 生命奇旅 LifeVoyage · 项目说明与使用说明

> 面向阅读者（课程检查、项目了解、快速上手）的简明说明。
> 面向开发者的安装与构建入口见仓库根目录 `README.md`；开发迭代记录见 `STATUS.md`。

## 1　项目简介

「生命奇旅」是一个**纯前端、无需后端**的三维人体科普应用：把人体变成可旋转、可点击、会流动的模型，用于直观认识器官位置、循环与神经系统，以及健康与病变的可视化对比。

- 定位：交互式 3D 人体科普 / 教育演示，单页应用，浏览器直接运行
- 基调：温暖、明亮，血液用发光粒子流表达，不作写实血腥呈现
- 红线：不提供诊断、用药或治疗建议；所有数字型医学事实标注来源

在线仓库：[GitHub](https://github.com/yuiaoch19-cyber/life-voyage-3d) ｜ [Gitee](https://gitee.com/wuyuiao/life-voyage-3d)

## 2　运行方式

环境：Node.js ≥ 20，支持 WebGL 2 的现代浏览器（Chrome / Edge / Firefox）。

```bash
npm install
npm run dev        # 打开 http://127.0.0.1:5173
npm run build      # 产出纯静态 dist/，可直接部署
```

首次加载需下载约 21 MB 模型，正常网络下约 6 秒；加载页有进度提示，失败时显示同风格错误页与「重试」按钮。仓库已包含运行所需的全部成品模型，无需额外下载。

## 3　界面组成

| 区域 | 位置 | 作用 |
|---|---|---|
| 顶栏 | 顶部 | 系统筛选（10 个系统）、搜索框、器官导航按钮（窄屏）、关于 |
| 左栏 | 左侧 | 按系统分组的器官列表，悬停联动高亮，点击选中 |
| 三维视图 | 中央 | 可旋转、缩放的人体；悬停描边与提示，点击选中器官 |

| 底部控制台 | 底部 | 模式条、五个图层域、特别功能（剖切 / 心率 / 视角 / 截图） |

## 4　功能一览

| 模块 | 内容 |
|---|---|
| 器官与实体 | 23 个可交互实体（17 器官 + 6 神经节点）：点击隔离、悬停描边、信息面板 |
| 体格层 | X 光 / 实体 / 隐藏三模式 + 透明度滑杆；骨骼、肌肉视图按类型过滤 |

| 神经系统 | 神经网 + 221 条信号流道，波包式传导动画 |
| 病变模拟 | 4 组病变配置 + 健康/病变 A/B 并排对比 + 血管斑块 |
| 系统筛选 | 全部 / 循环 / 呼吸 / 消化 / 神经 / 泌尿 / 免疫 / 体表 / 骨骼 / 肌肉 |

| 输出与适配 | 截图导出、移动端抽屉导航与 LOD 降级、键盘与读屏支持 |

## 5　基本操作

1. **旋转 / 缩放**：在三维视图中拖动旋转，滚轮缩放；双击空白处回到全景。
2. **切换系统**：点击顶栏的系统名称，不相关器官淡出；「全部」恢复。
3. **查看器官**：左栏点击、搜索后回车，或直接点击模型上的器官；相机飞近并弹出信息面板。再次点击空白处或按 `Esc` 取消选中。
4. **查看血流**：底部「脉管」域打开「血流」开关；点击模式条「透视」可只看血流与半透明轮廓。
5. **调整体格层**：底部「体格」域切换 X 光 / 实体 / 隐藏，拖动「透明」滑杆看进体内。
6. **剖切**：底部「剖切」选择矢状或冠状后，拖动位置滑杆。
7. **教学演示**：模式条「巡游」自动讲解，「测验」进入找器官答题；消化系统下自动播放食物之旅。
8. **导出**：点击「截图」保存当前画面为 PNG；「视角」重置机位并取消选中。

### 关于「按钮置灰」

底部控制台的控件有三种状态：**可用 / 关闭 / 锁定**。锁定时会置灰并在悬停提示中写明原因，模式条也会显示当前说明——例如透视模式接管了体格层与血流、测验中禁用图层开关以免提示答案、当前系统不含循环内容时脉管域不可用。这是有意的层次设计，**不会出现「能点但没反应」或「不让点却还在显示」**；点「退出当前模式」或「退出聚焦」即可恢复。

## 6　技术实现与规模

| 项 | 说明 |
|---|---|
| 技术栈 | three.js r170 + TypeScript（strict）+ Vite 5，无前端框架、无后端 |
| 渲染 | WebGL 2；`EffectComposer` + `OutlinePass`；DRACO 压缩 GLB；`three-mesh-bvh` 加速拾取 |
| 粒子 | 曲线采样点烘焙进半浮点 `DataTexture`，顶点着色器按进度采样，单绘制调用承载 13.8 万粒子 |
| 状态管理 | 单一 `Store` + 纯函数派生可见性与控件三态；模式与聚焦正交，带快照恢复 |
| 标注 | CSS2D 锚点 + BVH 遮挡淡出 + 屏幕空间两轮避让 |
| 规模 | 24 个 TS/CSS 文件约 3,320 行；5 个 GLB 合计 20.67 MiB；构建 JS 922 kB（gzip 261 kB） |

## 7　质量验证

项目在真实浏览器（Chromium / WebGL 2）中做了表驱动回归：能力矩阵 10/10、整体回归 5/5、聚焦态用例 10/10，运行期零控制台错误、零未捕获异常、零 404。全景标注重叠由 42 对降至 1 对，窄屏控制台高度由 316 px 压缩至 129 px。测试脚本与截图见工作区 `life-voyage-test/`，研究性总结见工作区根目录的学术论文。
